Source spec and a live poller

PR #6, PR #7

What was done

  • Pydantic SourceSpec with policies; mypy strict added to CI.
  • Poller: retries with backoff and jitter, content-addressed raw storage, JSON logs, graceful shutdown.
  • Citi Bike terms reviewed and the source enabled; the first live poll stored a snapshot, the second identical poll was skipped.

Problems and fixes

  • Namespace package. ImportError ... (unknown location): ingestion/__init__.py was never created, so Python saw an empty package. Found by listing missing files.
  • Broken copy of a document. Nested code fences ended the chat code block early, leaving the shell waiting for EOF. Fixed by quoting with a longer fence.
  • Logs leaking URLs. httpx logged every request with its full URL at INFO: noise, and a future API key in a query string would end up in logs. Raised httpx and httpcore to WARNING.

Lessons

  • Run against the real source early; the first run found a security issue no unit test covered.
  • Changed the working format: concept and diagram first, then code, then questions.
