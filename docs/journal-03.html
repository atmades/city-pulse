CI and branch protection

PR #1

What was done

  • GitHub Actions: python (lint, tests) and secrets (gitleaks over full history) jobs.
  • First change through branch, pull request, green checks and squash merge.
  • main protected by a ruleset created through the API: pull request required, checks required, no force push.

Problems and fixes

  • Protection silently off. A test push to main succeeded: the ruleset was not active. Removed the test commit with --force-with-lease, recreated the ruleset as code via the API, verified the push is now rejected.

Lessons

  • Verify a control by trying to break it, not by trusting the settings page.
