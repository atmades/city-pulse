Key concepts

The ideas behind the code. Each one comes with a question an interviewer is likely to ask; try answering before opening the hint.

Onboarding by configuration

The platform provides capabilities; sources only describe themselves. A new source is a YAML file and a contract, with no change to platform code.

Interview question

How would you know the platform approach worked? Hint: the second city or a new feed is onboarded without touching src/.

Policy as code

Rules live in the model and run in CI: no polling faster than 15 seconds, no enabled source without reviewed terms, no data files in git.

Interview question

Why is a rule in a wiki weaker than a rule in a test? Hint: nobody has to remember to check it.

Idempotent ingestion

The storage key is the hash of the content, so fetching the same snapshot twice writes it once. Retries and restarts never create duplicates.

Interview question

The poller crashes after writing a file and restarts. What happens, and what would happen if the key were the download time? Hint: same hash, same key, skip; a timestamp key would store a duplicate.

Resilience to source failures

Transient errors (429, 5xx, network) are retried with exponential backoff and jitter within a budget. Permanent errors fail fast. A source outage is logged; a bug stops the process so the orchestrator restarts it.

Interview question

Why add random jitter to backoff? Hint: many clients failing together would otherwise retry together.

Ports and adapters

The core talks to a SnapshotStore interface. Local files, S3, GCS and the in-memory test double all implement it.

Interview question

How do you test storage logic without a cloud account? Hint: inject a fake that implements the same two methods.

Graceful shutdown

On SIGTERM the poller finishes the current poll and exits. Writes go to a temporary file and are renamed, so a killed process never leaves a half-written snapshot.

Interview question

Why stop.wait() instead of time.sleep()? Hint: Kubernetes gives about 30 seconds before SIGKILL; sleep(60) would ignore the signal.
