Kickoff and scope

Spec review

What was done

  • Reviewed the original spec: about 18 weeks of work and several paid managed services.
  • Decided to build in vertical slices so every sprint ends with something that runs.
  • Repository language is English; Python everywhere (Beam in Python, not Java); dbt added for marts.

Problems and fixes

  • Budget question. A $300 free trial was read as a payment. Clarified the difference between the free trial (credits, card for identity only) and the Always Free tier. Outcome: zero-cost strategy, later ADR-007.

Lessons

  • Cost is an architecture input, not an afterthought.
