Handbook and GitHub Pages

PR #8, #9

What was done

  • Moved architecture, configuration and decisions out of chat into this multi-page handbook with a development journal and architecture history.
  • GitHub Pages serves the site from main, folder docs/; English and Russian versions; auto-merge enabled.

Problems and fixes

  • Pages returned 404. Pages was enabled before any page reached main: the archive with the site was never unpacked, so the commit was empty and no pull request was created. Fixed by adding the files, merging, then checking the Pages build status.
  • Merge raced the checks. Merging right after creating a pull request was rejected because checks had not started. Enabled auto-merge so GitHub merges once checks pass.

Lessons

  • Check what is actually on the default branch before debugging the host that serves it.
  • Documentation that lives next to the code changes in the same pull request and does not drift.
