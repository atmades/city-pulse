Architecture over time

Each diagram shows the system right after one change. Highlighted blocks are new in that step, plain blocks were already there, dashed blocks are planned. Read top to bottom to see how the platform grew.

  1. v1 · 2026-09-30

    Guardrails before code

    PR #1, #2
    newLaptoppre-commit: ruff, gitleaks
    →
    newPull requestone change, one review
    →
    newCIpython, secrets
    →
    newmainprotected by ruleset
    What changed
    Commit-time checks, CI on every pull request, a protected main branch.
    Why
    Every change is checked before it reaches main, and secrets never enter git history.
  2. v2 · 2026-10-01

    Infrastructure as code

    PR #3
    Pull request
    →
    newCI+ terraform fmt, validate
    →
    main
    newTerraformlocal state
    →
    newBigQueryraw, staging, curated, marts, ops
    →
    newService accountsone per component
    What changed
    Terraform creates the GCP dev environment; CI validates Terraform on every pull request.
    Why
    The environment can be rebuilt from scratch, and every component gets only the access it needs.
  3. v3 · 2026-10-25

    Sources as configuration

    PR #6
    newsources/*.yamlone file per source
    →
    newSourceSpecPydantic model and policies
    →
    newCI+ mypy strict, spec validation
    What changed
    A typed model for source specs; every YAML file in sources/ is validated in CI. mypy strict added.
    Why
    A new source becomes a reviewed YAML file instead of new code, and policies are enforced automatically.
  4. v4 · 2026-10-25

    First live data

    PR #7
    sources/citibike…enabled after terms review
    →
    newPollerretries, backoff, jitter
    →
    newCiti Bike GBFSexternal source
    newLocalFileStoreraw/name/dt=day/sha256
    →
    newJSON logsstdout, one event per line
    What changed
    A poller fetches Citi Bike station status every 60 seconds and archives each new snapshot under a content hash.
    Why
    Real data flows end to end; duplicates are impossible by design, and source outages do not stop the platform.
