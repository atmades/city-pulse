Конфигурация источников

Источник — это один YAML-файл в sources/, который проверяется моделью SourceSpec. Неизвестные поля считаются ошибкой, поэтому опечатка роняет CI, а не проходит незамеченной.

Настройки запуска

Одна сборка работает везде, меняются только переменные окружения: ноутбук, CI или кластер. Личные значения лежат в .env, который git игнорирует; .envrc загружает их через direnv и стирает учётные данные, унаследованные от других проектов.

ПеременнаяКто используетПо умолчанию / пример

КомандаКоды выхода
