Спецификация источника и живой poller

PR #6, PR #7

Что сделано

  • SourceSpec на Pydantic с политиками; в CI добавлен mypy strict.
  • Poller: повторы с backoff и jitter, хранение по хешу содержимого, JSON-логи, корректное завершение.
  • Условия Citi Bike прочитаны, источник включён; первый живой опрос сохранил снимок, второй такой же был пропущен.

Проблемы и решения

  • Пустой пакет. ImportError ... (unknown location): ingestion/__init__.py так и не был создан, и Python видел пустой пакет. Нашли, перечислив отсутствующие файлы.
  • Документ скопировался не целиком. Вложенные блоки кода раньше времени закрыли блок в чате, и оболочка ждала EOF. Исправили внешним блоком с более длинными кавычками.
  • URL в логах. httpx писал каждый запрос с полным URL на уровне INFO: шум, а будущий ключ API в параметрах запроса оказался бы в логах. Подняли уровень httpx и httpcore до WARNING.

Выводы

  • Запускайтесь на реальном источнике как можно раньше: первый же запуск нашёл проблему безопасности, которую не покрывал ни один тест.
  • Сменили формат работы: сначала концепция и схема, потом код, потом вопросы.
