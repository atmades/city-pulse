Google Cloud и Terraform

PR #3

Что сделано

  • Проект GCP без биллинга (BigQuery sandbox), пять датасетов по слоям, четыре service account'а с минимальными правами.
  • План сохранён через -out и применён ровно в проверенном виде; повторный план показал «нет изменений» (идемпотентность).
  • direnv для окружения проекта; Terraform fmt и validate в CI, обязательны для merge.

Проблемы и решения

  • Не приняты условия. Проект не создавался, пока аккаунт не принял условия Google Cloud в консоли.
  • Homebrew заблокирован. Устаревшие Command Line Tools и 7,8 ГБ свободного места. Поставили Terraform отдельным бинарником.
  • 403 от Terraform. gcloud работал, а Terraform нет. По очереди проверили аккаунт gcloud, владельца проекта и ADC: глобальная GOOGLE_APPLICATION_CREDENTIALS указывала на ключ другого проекта. Решили изоляцией окружения через direnv.
  • Файл плана не игнорировался. У tfplan нет расширения, поэтому правило *.tfplan его не ловило. Добавили правило и тест на него.

Выводы

  • Отлаживайте учётные данные, спрашивая каждый слой, кем он вас считает.
  • Шаблон в .gitignore защищает только те имена, которые вы реально используете.
