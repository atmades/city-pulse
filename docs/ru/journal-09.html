Справочник и GitHub Pages

PR #8, #9

Что сделано

  • Перенесли архитектуру, конфигурацию и решения из чата в этот многостраничный справочник с журналом и историей архитектуры.
  • GitHub Pages раздаёт сайт из main, папка docs/; версии на английском и русском; включён auto-merge.

Проблемы и решения

  • Pages отдавал 404. Pages включили раньше, чем страницы попали в main: архив с сайтом не распаковался, коммит был пустым, и PR не создался. Исправили: добавили файлы, влили PR, проверили статус сборки Pages.
  • Merge обогнал проверки. Merge сразу после создания PR отклонялся: проверки ещё не стартовали. Включили auto-merge, теперь GitHub вливает PR сам, когда проверки зелёные.

Выводы

  • Прежде чем отлаживать хостинг, проверьте, что реально лежит в основной ветке.
  • Документация рядом с кодом меняется в том же pull request и не расходится с ним.
