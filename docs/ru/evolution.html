Архитектура во времени

Каждая схема показывает систему сразу после одного изменения. Подсвечены блоки, появившиеся на этом шаге, обычные были и раньше, пунктирные запланированы. Читайте сверху вниз, чтобы увидеть, как росла платформа.

новоебыло раньшев планах
  1. v1 · 2026-09-30

    Защита до кода

    PR #1, #2
    новоеНоутбукpre-commit: ruff, gitleaks
    →
    новоеPull requestодно изменение, одно ревью
    →
    новоеCIpython, secrets
    →
    новоеmainзащищена ruleset
    Что изменилось
    Проверки при коммите, CI на каждый pull request, защищённая ветка main.
    Зачем
    Любое изменение проверяется до попадания в main, а секреты никогда не попадают в историю git.

    Инфраструктура как код

    PR #3
    Pull request
    →
    новоеCI+ terraform fmt, validate
    →
    main
    новоеTerraformstate локально
    →
    новоеBigQueryraw, staging, curated, marts, ops
    →

    Что изменилось
    Terraform создаёт dev-окружение в GCP; CI проверяет Terraform в каждом pull request.
    Зачем
    Окружение можно пересоздать с нуля, и каждый компонент получает только нужные ему права.
  3. v3 · 2026-10-25

    Источники как конфигурация

    PR #6
    новоеsources/*.yamlодин файл на источник
    →
    новоеSourceSpecмодель Pydantic и политики
    →
    новоеCI+ mypy strict, проверка спецификаций
    Что изменилось
    Типизированная модель описания источника; каждый YAML в sources/ проверяется в CI. Добавлен mypy strict.
    Зачем
    Новый источник — это YAML-файл на ревью, а не новый код, и политики проверяются автоматически.
  4. v4 · 2026-10-25

    Первые живые данные

    PR #7
    sources/citibike…включён после проверки условий
    →
    новоеPollerповторы, backoff, jitter
    →
    новоеCiti Bike GBFSвнешний источник
    новоеLocalFileStoreraw/имя/dt=день/sha256

    Что изменилось
    Poller раз в 60 секунд забирает статус станций Citi Bike и сохраняет каждый новый снимок под хешем содержимого.
    Зачем
    Реальные данные идут от начала до конца; дубли невозможны по устройству, а сбои источника не останавливают платформу.
