Google Cloud and Terraform

PR #3

What was done

  • GCP project without billing (BigQuery sandbox), five datasets per layer, four least-privilege service accounts.
  • Plan saved with -out and applied as reviewed; a second plan showed no changes (idempotency).
  • direnv for per-project environment; Terraform fmt and validate in CI, required to merge.

Problems and fixes

  • Terms of Service not accepted. Project creation failed until the account accepted Google Cloud terms in the console.
  • Homebrew blocked. Outdated Command Line Tools and 7.8 GB free disk. Installed Terraform as a plain binary instead.
  • 403 from Terraform. gcloud worked but Terraform did not. Checked gcloud account, project owner and ADC in turn: a global GOOGLE_APPLICATION_CREDENTIALS pointed to another project's key. Fixed by isolating the environment with direnv.
  • Plan file not ignored. tfplan has no extension, so *.tfplan missed it. Added the rule and a test for it.

Lessons

  • Debug credentials by asking each layer who it thinks you are.
  • A pattern in .gitignore only protects the names you actually use.
