Repository and guardrails

commits 21c1817, c7ec313

What was done

  • Folder structure mirrors the architecture; .gitignore blocks data, secrets and Terraform state.
  • uv, ruff, pytest; repository rules turned into tests (policy as code).
  • pre-commit with gitleaks, private key detection and Conventional Commits.

Problems and fixes

  • Files contained a shell command. Copying the command instead of the content wrote pbpaste > file into pyproject.toml. Fix: self-contained cat > file <<'EOF' blocks.
  • Linter caught our own code. ruff flagged a 102-character line and a missing final newline; ruff format fixed both.
  • Commit refused. pre-commit refuses to run while its own config is unstaged; git add first.

Lessons

  • A leaked key stays in git history forever: rotate it, then rewrite history. Prevention beats cleanup.
