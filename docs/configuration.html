Source configuration

A source is one YAML file in sources/, validated by SourceSpec. Unknown keys are errors, so a typo fails CI instead of being ignored.

FieldRuleWhy
namesnake_case, 3–63 chars, uniqueBecomes part of storage paths and table names
kindrealtime_feed or batch_fileDecides whether a polling policy is required
formatgtfs_rt, json, parquetSets the file extension and, later, the parser
endpointvalid http(s) URLWhere the poller fetches from

Runtime configuration

One build runs everywhere; only environment variables change between a laptop, CI and a cluster. Personal values live in .env, which git ignores; .envrc loads them through direnv and clears credentials inherited from other projects.
